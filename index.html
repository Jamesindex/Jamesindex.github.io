3 分钟上线到 GitHub Pages & 绑定独立域名

第 1 步：下载当前网页文件

点击页面右上角的 “下载 index.html” 按钮，将完整的单文件网页保存到本地电脑。

第 2 步：创建免费 GitHub 公开仓库
  1. 登录 GitHub，点击右上角 + → New repository。
  2. 仓库名称填写 你的用户名.github.io，权限选择 Public。
  3. 点击 uploading an existing file，把刚下载的 index.html 拖进去并点击 Commit changes。
  4. 等待 30 秒，直接访问 https://你的用户名.github.io/ 即可免费查看！
第 3 步：（可选）绑定你自己的独立域名
  • 二级域名（推荐，如 ai.yourdomain.com）：去域名商 DNS 后台添加一条 CNAME 记录，主机填 ai，指向 你的用户名.github.io。
  • 根域名（如 yourdomain.com）：添加 4 条 A 记录（主机 @），分别指向 185.199.108.153 ~ 111.153。
  • 回到 GitHub 仓库 → Settings → Pages → Custom domain 输入你的域名并保存，勾选 Enforce HTTPS 即可获得免费 SSL 证书。
